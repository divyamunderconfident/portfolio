# Project rules
- This is Divyam Saini's personal portfolio site. Stack: Next.js (App Router) + TypeScript + Tailwind, deployed on Vercel. No backend, no database, no paid services.
- Ship fast: work autonomously, make reasonable choices without asking, and list the choices you made at the end. Ask only if truly blocked (a missing file or login).
- The Claude Design export lives in Design/ (not committed). Implement it faithfully, but phone-first: every page must work at 375px with no horizontal scroll and no cut-off text.
- All project content lives in one data file (content/projects.ts). Adding a project = adding one entry; cards, skills highlighting and case-study pages are generated from it.
- Never invent facts or numbers. Use only what is in content/ or the design; anything missing stays a clearly marked placeholder, listed at the end of each task.
- Motion stays tasteful, respects prefers-reduced-motion, and never blocks reading. Custom cursor on fine pointers only.
- Accessibility: semantic HTML, keyboard navigation, visible focus, 4.5:1 text contrast, alt text.
- Commit and push after every working milestone.
